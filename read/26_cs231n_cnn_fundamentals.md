## 📏 第一部分: k-最近邻 (kNN)

### 算法原理

```

核心思想:
  "物以类聚"

测试图像分类:
  1. 计算与所有训练图像的距离
  2. 找到 k 个最近的邻居
  3. 对邻居标签投票
  4. 得票最多的标签获胜

距离度量:

  L1 (曼哈顿):
    d₁(x, y) = Σᵢ |xᵢ - yᵢ|

  L2 (欧几里得):
    d₂(x, y) = √[Σᵢ (xᵢ - yᵢ)²]
```

### 伪代码

```python
def predict_knn(x_test, X_train, y_train, k, distance='l2'):
    # 计算距离
    if distance == 'l1':
        distances = sum(|X_train - x_test|)
    else:  # l2
        distances = sqrt(sum((X_train - x_test)²))

    # 找到 k 个最近邻
    k_nearest = argsort(distances)[:k]
    k_labels = y_train[k_nearest]

    # 多数投票
    return mode(k_labels)
```

### 超参数调优

```

k 的选择:

k = 1 (过拟合):
  - 对噪声敏感
  - 记忆训练数据
  - 训练准确率高
  - 测试准确率低

k 适中 (平衡):
  - 平滑决策边界
  - 对噪声鲁棒
  - 泛化性能好

k 过大 (欠拟合):
  - 过度平滑
  - 边界过于简单
  - 偏向多数类

经验法则:
  - 小数据集: k ≈ √N
  - 大数据集: k ≈ N/100
```

### 优缺点

```

优点:
  ✓ 简单直观
  ✓ 无训练过程
  ✓ 理论最小

缺点:
  ✗ 测试时慢 (需要遍历所有数据)
  ✗ 对高维数据效果差
  ✗ 无法学习特征
  ✗ 内存消耗大

实际应用:
  - 基线对比
  - 快速原型
  - 教学演示
```

## 📊 第二部分: 线性分类器

### 得分函数

```

线性分类器:

f(x; W, b) = Wx + b

其中:
  - x ∈ ℝ^D: 输入图像 (展平为 3072 维向量)
  - W ∈ ℝ^C×D: 权重矩阵 (10 × 3072)
  - b ∈ ℝ^C: 偏置向量 (10)
  - f ∈ ℝ^C: 类别得分 (10)

直观理解:
  - 每个类有一个"模板"
  - W 的每一行是一个类的模板
  - 内积衡量相似度
  - 得分最高者获胜
```

### 损失函数

#### 1. SVM 损失 (Hinge Loss)

```

公式:

L = (1/N) Σᵢ Σⱼ≠yᵢ max(0, sⱼ - s_{yᵢ} + Δ)

其中:
  - sⱼ: 第 j 个类别的得分
  - s_{yᵢ}: 正确类别的得分
  - Δ = 1: 边界参数

直观理解:
  - 正确类得分至少比错误类高 Δ
  - 否则累计损失

例子:
  正确类别 (猫): s_cat = 3.2
  错误类别 (狗): s_dog = 4.5

  margin = s_dog - s_cat = 4.5 - 3.2 = 1.3

  由于 1.3 > Δ=1:
  损失 = 1.3 - 1 = 0.3
```

#### 2. Softmax 损失 (交叉熵)

```

公式:

L = -(1/N) Σᵢ log(e^{s_{yᵢ}} / Σⱼ e^{sⱼ})

其中:
  - s_{yᵢ}: 正确类别的得分
  - 分母: 归一化项 (所有类别的指数和)

直观理解:
  - 将得分转换为概率
  - 最大化正确类的对数概率

例子:
  得分: [2.0, 3.0, 1.0, 0.5]
  Softmax: [0.23, 0.62, 0.10, 0.05]
  正确类: 1 (概率 0.62)

  损失: -log(0.62) ≈ 0.48
```

### 正则化

```

目的: 防止过拟合

总损失:
  L_total = L_data + λ·R(W)

正则化类型:

L2 (权重衰减):
  R(W) = Σᵢⱼ Wᵢⱼ²

  - 鼓励小权重
  - 平滑决策边界
  - 最常用

L1:
  R(W) = Σᵢⱼ |Wᵢⱼ|

  - 鼓励稀疏性
  - 特征选择

弹性网络:
  R(W) = α·L1 + (1-α)·L2

  - 结合两者
  - Ridge Lasso 折衷
```

### 梯度计算

```

Softmax 梯度推导:

1. 前向传播:
   scores = X·W + b
   probs = softmax(scores)

2. 损失:
   L = -log(probs[correct_class])

3. 梯度 (反向传播):
   ∂L/∂scores = probs - one_hot(y)
   ∂L/∂W = X^T · ∂L/∂scores
   ∂L/∂b = ∂L/∂scores

实现要点:
  • 数值稳定性: 减去最大得分
  • 小常数: 避免 log(0)
```

## 🚀 第三部分: 优化算法

### 随机梯度下降 (SGD)

```

标准 SGD:

w_{t+1} = w_t - η·∇L(w_t)

其中:
  - η: 学习率
  - ∇L: 梯度
  - t: 迭代次数

特点:
  ✓ 简单
  ✓ 内存少
  ✗ 噪声大
  ✗ 可能陷入局部最小值
```

### SGD + 动量

```

动量方法:

v_{t+1} = ρ·v_t - η·∇L(w_t)
w_{t+1} = w_t + v_{t+1}

其中:
  - ρ: 动量系数 (通常 0.9)
  - v: 速度项

直观理解:
  - 像球滚下山
  - 积累速度
  - 跨越平台期

优势:
  ✓ 加速收敛
  ✓ 减少震荡
  ✓ 冲出局部最小值
```

### Adam 优化器

```

Adam (Adaptive Moment Estimation):

m_t = β₁·m_{t-1} + (1-β₁)·g_t
v_t = β₂·v_{t-1} + (1-β₂)·g_t²
m̂_t = m_t / (1-β₁^t)
v̂_t = v_t / (1-β₂^t)
w_{t+1} = w_t - η·m̂_t / (√v̂_t + ε)

其中:
  - m: 一阶矩估计
  - v: 二阶矩估计
  - β₁, β₂: 衰减率 (通常 0.9, 0.999)
  - ε: 小常数 (1e-8)

特点:
  ✓ 自适应学习率
  ✓ 鲁棒
  ✓ 默认选择
```

### 学习率调度

```

阶梯衰减:
  η_t = η₀ · γ^{⌊t/T⌋}

  每 T 步衰减 γ 倍 (通常 0.5 或 0.1)

指数衰减:
  η_t = η₀ · e^{-kt}

  指数衰减

逆时衰减:
  η_t = η₀ / (1 + k·t)

  逐渐降低

预热:
  前几轮使用小学习率
  逐渐增加到目标值

重启:
  在不同学习率间循环
  周期性重置
```

## 🧠 第四部分: 神经网络

### 两层网络

```

架构:

输入层: x (3072)
  ↓
隐藏层: h = ReLU(W₁x + b₁)  (100)
  ↓
输出层: y = W₂h + b₂  (10)

前向传播:
z₁ = x·W₁ + b₁          # 线性变换
h = max(0, z₁)           # ReLU 激活
y = h·W₂ + b₂           # 输出得分
```

### 反向传播

```

核心思想: 链式法则

输出层梯度:
∂L/∂y = probs - one_hot(y)
∂L/∂W₂ = h^T · ∂L/∂y
∂L/∂b₂ = ∂L/∂y

隐藏层梯度:
∂L/∂h = ∂L/∂y · W₂^T
∂L/∂z₁ = ∂L/∂h ⊙ (z₁ > 0)  # ReLU 导数
∂L/∂W₁ = x^T · ∂L/∂z₁
∂L/∂b₁ = ∂L/∂z₁

其中:
  ⊙: 逐元素乘法
  (z₁ > 0): ReLU 的导数 (0 或 1)
```

### 激活函数

```

ReLU (推荐):
  f(x) = max(0, x)
  f'(x) = 1 if x > 0 else 0

  ✓ 计算快
  ✓ 缓解梯度消失
  ✓ 稀疏激活

Sigmoid:
  f(x) = 1/(1 + e^{-x})
  f'(x) = f(x)(1-f(x))

  ✗ 梯度消失
  ✗ 饱和
  ✗ 非零中心

Tanh:
  f(x) = (e^x - e^{-x})/(e^x + e^{-x})
  f'(x) = 1 - f(x)²

  ✓ 零中心
  ✗ 梯度消失
```

## 🖼️ 第五部分: 卷积神经网络

### 为什么需要卷积？

```

全连接层的问题:

图像 32×32×3 = 3072 维
全连接层 3072 → 100 = 307,200 参数

问题:
  ✗ 参数太多 (容易过拟合)
  ✗ 忽略空间结构
  ✗ 计算量大

卷积的解决方案:
  ✓ 参数共享
  ✓ 局部连接
  ✓ 平移不变性
```

### 卷积操作

```

二维卷积:

y[i,j] = Σₘ Σₙ W[m,n] · x[i+m, j+n]

其中:
  - W: 卷积核/滤波器
  - x: 输入特征图
  - K × K: 滤波器大小 (如 3×3, 5×5)

参数:
  - Stride (步长): 滑动窗口的步长
  - Padding (填充): 边界填充 (0 或 1)

输出尺寸:
  H_out = (H + 2P - K) / S + 1
  W_out = (W + 2P - K) / S + 1
```

### 池化

```

最大池化:

y[i,j] = max_{m,n ∈ region} x[m,n]

典型配置:
  2×2 窗口
  步长 2

效果:
  - 尺寸减半
  - 平移不变性
  - 控制过拟合

例子:
  输入: 4×4 特征图
  池化: 2×2 窗口
  输出: 2×2 特征图
```

### CNN 架构

```

Mini AlexNet:

输入: 32×32×3
  ↓
Conv 5×5, 32 filters + ReLU + MaxPool
  → 16×16×32
  ↓
Conv 3×3, 64 filters + ReLU + MaxPool
  → 8×8×64
  ↓
Flatten
  → 4096
  ↓
FC 4096 → 256 + ReLU
  → 256
  ↓
FC 256 → 10
  → 10 (类别得分)
```

### 参数效率

```

CNN vs 全连接:

CNN:
  Conv1: 32 × (5×5×3 + 1) ≈ 2.4K
  Conv2: 64 × (3×3×32 + 1) ≈ 18.5K
  FC: 1.0M
  总计: ≈ 1.0M 参数

全连接:
  3072 → 100: 307K
  100 → 100: 10K
  总计: ≈ 30M 参数

优势: CNN 参数少 30×
```

## 💡 第七部分: 训练技巧

### 数据预处理

```

归一化:
  X_norm = (X - μ) / σ

  - μ: 训练集均值
  - σ: 训练集标准差
  - 零均值、单位方差

数据增强:
  - 随机裁剪
  - 水平翻转
  - 颜色抖动
  - 旋转、缩放

效果:
  ✓ 提高泛化
  ✓ 增加数据量
  ✓ 减少过拟合
```

### 权重初始化

```

Xavier 初始化:
  W ~ N(0, √(2/n_in))

  - 适合 tanh/sigmoid
  - 保持方差

He 初始化:
  W ~ N(0, √(2·2/n_in))

  - 适合 ReLU
  - 考虑 ReLU 死区

偏置:
  b = 0
  - 小常数也可
```

### 空智检查

```

1. 检查初始损失:
   Softmax (C 类): 应约为 -log(1/C)
   例如: 10 类 → -log(0.1) ≈ 2.3

2. 过拟合小数据集:
   - 50 个样本
   - 训练 1000 轮
   - 应该达到 ~100% 准确率

3. 检查梯度:
   - 数值梯度 vs 解析梯度
   - 相对误差 < 1e-7

4. 监控训练:
   - 损失应该下降
   - 准确率应该上升
   - 训练/验证差距
```

### 超参数调优

```

学习率 (最重要!):
  太高: 损失爆炸
  太低: 不学习
  最佳: 1e-3 到 1e-4

正则化强度:
  太弱: 过拟合
  太强: 欠拟合
  最佳: 验证集调优

批次大小:
  32: 噪声大但更新快
  256: 平滑但更新慢
  最佳: 视 GPU 内存

优化器:
  - 简单任务: SGD
  - 复杂任务: Adam
  - 训练快: Momentum
```

### 常见问题

```

问题与解决:

1. 损失爆炸:
   → 降低学习率

2. 损失不下降:
   → 检查学习率
   → 检查代码

3. 过拟合:
   → 增加正则化
   → 数据增强

4. 欠拟合:
   → 减少正则化
   → 增加模型容量

5. 梯度消失:
   → 使用 ReLU
   → 残差连接
```
