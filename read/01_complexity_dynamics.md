### **第 2 部分：测量熵的增长**（第 5 单元格）

#### **香农熵（Shannon Entropy）**
```python
def measure_entropy_over_time(history):
    # 计算每个时间步的熵
    ent = entropy(probs, base=2)  # 以比特为单位
```

**熵的含义**：
- **低熵** = 有序、可预测（如：所有细胞都是 0）
- **高熵** = 无序、随机（如：0 和 1 均匀分布）

**观察到的现象**：
```
初始熵 ≈ 0.1 bits（简单）
最终熵 ≈ 1.0 bits（最大混乱）
```

## 🔑 关键要点

### 1. **复杂度增长**
```
简单初始条件 + 简单规则 → 复杂涌现行为
```
**例子**：Rule 30 从单个细胞生成混沌图案

### 2. **熵增加（第二定律）**
```
低熵 → 高熵
有序 → 无序
```
**测量方法**：香农熵从 ~0.1 增长到 ~1.0 bits

### 3. **不可逆性**
```
容易混合咖啡 ☕
不可能分离回原状态 ❌
```
**原因**：混合后的状态数量指数级增长

### 4. **计算不可逆性**
某些过程在计算上**无法逆向**——这与密码学中的**哈希函数**原理相同！

## 🧠 与深度学习的联系

这个 notebook 如何关联到深度学习：

### **信息理论**
- 交叉熵损失函数就是基于香农熵
- `loss = -Σ y log(p)` 其中 p 是预测概率分布

### **表示学习**
- 神经网络学习的是**数据的压缩表示**
- 就像细胞自动机从简单规则产生复杂模式

### **正则化**
- 正则化本质上是**限制模型的复杂度**
- 防止过拟合（低熵状态）

### **信息瓶颈**
- 神经网络必须在**压缩信息**和**保留预测相关信息**之间平衡
- 类似于混合过程中的熵增

## 📝 代码关键片段解释

### Rule 30 实现细节

```python
def rule_30(left, center, right):
    # 将 3 个细胞状态组合成 3 位二进制数
    pattern = (left << 2) | (center << 1) | right
    rule = 30  # Rule 30 的二进制是 00011110
    return (rule >> pattern) & 1  # 提取对应位
```

**Rule 30 真值表**：
```
111 110 101 100 011 010 001 000  (left, center, right)
  0   0   0   1   1   1   1   0  (next state)
```
二进制 `00011110` = 十进制 30

### 熵计算公式

```python
ent = entropy(probs, base=2)
# 实际计算: H(X) = -Σ p(x) * log₂(p(x))
```

**最大熵**：当所有状态等概率时，熵达到最大
- 对于 2 个状态（0 和 1）：最大熵 = 1 bit
- 对于 n 个状态：最大熵 = log₂(n) bits

### 扩散方程

```python
new_grid[i, j] = (1 - rate) * grid[i, j] + rate * neighbors
# 这是离散化的热传导方程
```

**连续形式**：∂u/∂t = α∇²u（热方程）
